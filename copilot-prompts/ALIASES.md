# Copilot Command Aliases

Use these aliases instead of full file paths for clarity and speed.

## CMS Upgrade Aliases

### Full CMS Upgrade
```text
@modernize cms:full
```
### Phase A: Analysis
```text
@modernize cms:phase-a
```
### Phase B: Validation
```text
@modernize cms:phase-b
```
### Phase C: Platform Upgrade
```text
@modernize cms:phase-c
```
### Phase D: CMS Packages
```text
@modernize cms:phase-d
```
### Phase E-K: Code Refactoring
```text
@modernize cms:phase-e
```
